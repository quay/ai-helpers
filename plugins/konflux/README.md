# Konflux Plugin

Konflux advisory skills: query curated NotebookLM knowledge bases for Konflux concepts, pipelines, builds, releases, and troubleshooting.

## Skills

| Skill | Description |
|-------|-------------|
| `/konflux:advisor` | Query NotebookLM knowledge bases for Konflux concepts, pipelines, builds, releases, and troubleshooting |

## Prerequisites

- **`nlm` CLI** — install with `pipx install nlm`, then `nlm login` to authenticate
- **NotebookLM access** — the skill queries shared notebooks; open the links provided by the skill to add them to your Google account
